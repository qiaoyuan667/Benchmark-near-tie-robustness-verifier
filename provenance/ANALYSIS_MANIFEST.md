# Public analysis manifest

## Coverage

The artifact includes the primary spectral audit, all reported robustness and
interpretation analyses, direct logistic-MIRT comparison, discrimination-matched
controls, within-family specificity comparison, and capability-profile overlap
diagnostics. See `docs/PAPER_ARTIFACT_MAP.md` for implementation-to-result links.

`results/` contains frozen numeric outputs, not synthetic demonstrations. Seeds,
selected dimensions, input-content hashes, and protocol settings accompany them.
Some historical machine-oriented identifiers use `source` for the paper's
metadata-defined item groups; `v3` is an internal module identifier, not a second
analysis specification. Keep these identifiers when replaying code.

The original stability thresholds remain in the computational protocol for
traceability. Passing an author-chosen threshold is not evidence of universal
measurement quality; report effect sizes and their within-cell permutation
comparisons. Likewise, a nonsignificant reversal excess is not proof of robust
orderings or equivalent capabilities.

## Included reusable numeric records

- Per-fold and pooled summaries for all five benchmarks, including null results.
- Random-control and bootstrap count/rate replicates with no model identities.
- Anonymous annotation labels (500 items, 250 pairs, two annotators), sufficient
  to replay every reported content-audit statistical table offline.
- All five capability-matching scenarios, including weak coverage and nulls.
- Direct-MIRT and spectral candidate-wise CV losses and final outcomes.

## Deliberately not distributed

- Benchmark question text, original response matrices, model identifiers,
  uploader/owner names, or item-level fitted signatures and embeddings.
- Annotation rationales, prompts containing benchmark questions, backend logs,
  credentials, private file paths, or prior Git history.

Numeric inputs are reconstructed from independently hosted upstream files with
SHA-256 verification (`docs/DATA.md`). A checksum verifies a pinned file, not a
license grant or a guarantee that arbitrary pickle files are safe.

## Integrity boundary

`public_files.sha256` covers public deliverable bytes. `release_audit.json` is
generated by the release checker and records its actual checks. Neither claims
that a release build reruns every multi-hour experiment. Original aggregate
results are preserved; independent regression and replay checks are described
in `PACKAGING_VALIDATION.md`. Raw recomputation stays outside the repository.
